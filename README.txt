XYZ TRAVELS - DEMO WEBSITE
=========================
Extract the ZIP and open index.html, or upload the complete folder to Netlify / GitHub Pages.

PAGES: index.html, about.html, vehicles.html, destinations.html, booking.html, gallery.html, contact.html.
FEATURES: responsive multi-page navigation, sample vehicle and destination cards, booking form, live-updating sample fare calculator, WhatsApp enquiry links, Google Maps directions/map, gallery lightbox, floating WhatsApp button, developer credit.

DEMO DATA: XYZ Travels is fictional. Phone +91 98765 43210, hello@xyztravels.example, Agra demo office, owner Aarav Sharma, driver names/photos, testimonials, vehicle details, rates and capacities are sample placeholders. Replace before client production use.

FARE CALCULATOR: Uses manually entered distance and illustrative per-km rates. It is not connected to live Google Maps route distance. Toll, parking, taxes, driver allowance and availability are not automatically verified. Booking submits an enquiry only, not a confirmed reservation or payment.

IMAGES: Loaded from Unsplash image URLs. Internet connection required. Google Fonts, Maps and WhatsApp also need internet.

CHANGE WHATSAPP NUMBER: Edit PHONE in js/main.js and update displayed phone links in HTML.
COLORS / DESIGN: Edit css/style.css.
